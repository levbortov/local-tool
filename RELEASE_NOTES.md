# v0.3.1 — Статусы и управление состоянием

- Массовое раскрытие и сворачивание папок объединены в одну кнопку с адаптивным значком и подписью.
- Исправлен поворот шевронов открытых и закрытых папок.
- Добавлены индивидуальные индикаторы состояния каждого проверенного файла; состояние вложенных файлов агрегируется на родительских папках, в том числе закрытых.
- Рядом с кнопкой проверки файлов появился компактный статус-бар: проверено, не сохранено, изменено извне, ошибки и неполная проверка.
- Кнопка «Сохранить» недоступна для неизменённого сохранённого документа; Undo/Redo основаны на собственной истории текстовых правок и становятся неактивными, когда действий нет.
- Проверка диска запускается при выборе рабочего каталога и по кнопке обновления. Это не облачная синхронизация и не постоянное наблюдение за файлами. Сравниваются метаданные (размер и время изменения), обход ограничен 1500 элементами и глубиной 20 уровней.
- Тестирование: Chromium с имитацией File System Access API; реальное изменение файлов на компьютере не тестировалось.

# v0.3.0 — Рабочее пространство

Новая версия редактора **«Лист»** по двухпанельному эскизу: проводник слева, редактор справа, рабочие инструменты и статус снизу.

### Новое
- Создание папок и текстовых файлов в рабочей директории.
- Переименование документов, включая редактирование имени в заголовке; переименование папок.
- Перемещение файлов и папок между вложенными каталогами через диалог и перетаскиванием внутри проводника.
- Удаление файлов и папок с подтверждением, без корзины.
- Перетаскивание каталога с компьютера для смены рабочего пространства.
- Сворачиваемый сайдбар, который на узких экранах открывается поверх редактора.
- Переработанный двухпанельный интерфейс по эскизу.

### Дополнение инструментов проводника (исправление текущей v0.3.0)
- В нижней панели появились кнопки «Раскрыть все папки» и «Свернуть все папки».
- Добавлено меню сортировки: папки сначала А–Я / Я–А, по имени А–Я / Я–А.
- Режим сортировки сохраняется локально и применяется ко всем раскрытым папкам; выбранные раскрытия не теряются.
- Для защиты интерфейса массовое раскрытие ограничено 1000 папками и глубиной 20 уровней; при достижении предела показывается предупреждение.

### Исправления интерфейса без изменения версии
- Нижняя панель проводника и строка статуса редактора выровнены по одной горизонтали.
- Кнопка темы расположена слева от кнопки скрытия проводника; при свёрнутой панели доступна в редакторе.
- Ширина проводника изменяется перетягиванием разделителя и сохраняется в браузере (на мобильных экранах ширина фиксирована).
- В нижней панели проводника оставлена только кнопка обновления; создание и операции с файлами доступны в контекстном меню. Для создания в корне нажмите правой кнопкой на пустой области проводника.
- Перенос в корень и скрытие имён с точкой в начале сохранены.

### Важно
- Переименование и перемещение реализованы через копирование, проверку размера файлов и удаление источника: это **не атомарные операции**.
- Защита несохранённого текста и предупреждения перед опасными действиями.
- Нужны Chrome/Edge, File System Access API и разрешения на доступ.
- Проверено в Chromium с имитацией файловой системы: создание, переименование, перемещение, удаление, запись/чтение, темы, перенос строк и мобильный интерфейс. Реальный доступ к диску не тестировался — для важных данных используйте резервную копию.

# v0.2.0 — Проводник и темы

- Проводник рабочей директории с вложенными папками, открытием и созданием файлов.

# v0.1.0 — Первый выпуск: «Лист»

- Автономный текстовый редактор без форматирования.
- Открытие локальных файлов и прямое сохранение изменений.
- Создание документов, «Сохранить как», защита от несохранённых изменений, счётчики и горячие клавиши.
