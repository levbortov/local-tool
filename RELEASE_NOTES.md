# v0.2.0 — Проводник и темы

Второй выпуск автономного текстового редактора «Лист».

### Новое
- Проводник локальной рабочей папки с поддержкой вложенных директорий.
- Открытие файлов из проводника, создание новых файлов и обновление дерева.
- Три режима оформления: системный, светлый, тёмный.
- Сохранение выбранной темы между запусками (когда хранилище браузера доступно).

### Исправления
- Длинные строки автоматически переносятся на новую визуальную строку и больше не создают горизонтальную прокрутку.
- Текстовое поле подстраивается под реальные размеры своего контейнера.
- Стилизованы полосы прокрутки; улучшена адаптация под узкие экраны.

**Запуск:** скачайте `tools/list/index.html` и откройте файл в Chrome или Edge. Для работы с рабочей директорией нажмите «Папка…» и выберите папку. Приложение полностью автономно: интернет и сервер не нужны.

**Ограничения:** для прямой записи на диск требуется File System Access API и согласие пользователя. Работа с реальной файловой системой зависит от разрешений браузера; сценарии чтения/записи протестированы с имитацией File System Access API.

# v0.1.0 — Первый выпуск: «Лист»

Первый автономный инструмент проекта **local-tool**: текстовый редактор без форматирования.

- Открытие локальных текстовых файлов.
- Редактирование и сохранение изменений прямо в исходном файле через File System Access API.
- Создание документов и «Сохранить как».
- Предупреждение о несохранённых изменениях.
- Счётчики строк, слов, символов и сочетания клавиш.
