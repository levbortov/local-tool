# v0.1.0 — Первый выпуск: «Лист»

Первый автономный инструмент проекта **local-tool**: текстовый редактор без форматирования.

- Открытие локальных текстовых файлов
- Редактирование и сохранение изменений прямо в исходном файле через File System Access API
- Создание документов и «Сохранить как»
- Предупреждение о несохранённых изменениях
- Счётчики строк, слов, символов и сочетания клавиш

**Как использовать:** скачайте файл `index.html` из `tools/list/` и откройте его в Chrome или Edge. Бэкенд и интернет не требуются.

**Ограничения:** нужна поддержка File System Access API; доступ к локальным файлам предоставляется пользователем через системный диалог. Приложение не тестировалось с реальной файловой системой во всех браузерах.
