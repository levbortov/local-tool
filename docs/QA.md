# Проверки «Листа» v0.3.0

Проверки выполнены в headless Chromium с имитацией File System Access API. Взаимодействие с реальными системными диалогами и файловой системой ОС не проверялось.

Проверены сценарии: выбор рабочей папки, раскрытие вложенных директорий, открытие файлов; перенос длинных строк без горизонтальной прокрутки; размеры поля редактирования; сохранение изменений; создание файла и папки; переименование файла из заголовка и переименование папки; перемещение файла между папками; удаление папки; переключение светлой/тёмной темы; сворачивание сайдбара; адаптация под мобильную ширину и закрытие панели после открытия файла; замена рабочего каталога имитацией внешнего drag-and-drop.

До использования на важных данных необходимо вручную проверить запросы разрешений Chrome/Edge, сбои копирования и удаления, большие деревья директорий, перетаскивание каталогов из Finder/Проводника и повторное открытие после перезапуска браузера. Начните с тестовой копии папки.

## Дополнительная проверка исправлений v0.3.0

В Chromium с имитацией File System Access API проверены отсутствие внешней рамки при размере окна 1440×900 и 390×760, выбор темы через отдельное меню, отсутствие лишних кнопок, скрытие `.git`, `.DS_Store` и вложенного `.secret.md`, перенос файла в корень перетаскиванием на заголовок папки, перенос папки в корень на свободную область проводника, действие «Переместить в корень» через контекстное меню и его скрытие для объектов, уже лежащих в корне. Результат: проверки пройдены. Реальная файловая система ОС не использовалась.

## Проверка выравнивания и изменяемой ширины

В headless Chromium с имитацией File System Access API проверены совпадение координат верхней границы и высоты нижних панелей (56 px при 1440×900), единственная кнопка обновления внизу проводника, размещение темы непосредственно слева от скрытия сайдбара, смена темы, создание файла через контекстное меню корневой директории, наличие действий в контекстном меню объекта, перетаскивание разделителя (315→415 px), запись ширины в localStorage, изменение ширины стрелками и доступность темы при скрытом сайдбаре. Мобильная ширина 390 px: разделитель скрыт, боковая панель открывается поверх редактора, меню темы доступно. JavaScript-ошибок нет. Фактическое чтение/запись в ОС не проверялось.

## Проверка дополнения нижней панели (v0.3.0)

В Chromium с имитацией File System Access API проверены: недоступность инструментов без выбранной папки; раскрытие всех видимых вложенных директорий и сворачивание до корневого уровня; исключение скрытых файлов и папок; 4 варианта сортировки (А–Я и Я–А с размещением папок сначала либо в общем списке); сохранение настроек в localStorage; сохранение раскрытых ветвей при смене сортировки; закрытие меню по Escape; работа меню при узком экране и после изменения ширины сайдбара. Ошибок JavaScript в этих тестах не обнаружено. Реальная файловая система ОС не проверялась.

## Регрессия v0.3.1

В headless Chromium с имитацией File System Access API проверены единая кнопка раскрытия/сворачивания, корректный поворот шевронов, индикаторы отдельных файлов и наследование индикатора закрытой родительской папкой, общий статус панели, обработка несохранённых изменений и внешних модификаций по обновлению, исчезновение предупреждения при повторном открытии, ошибки чтения метаданных и восстановление после ошибки, отключение Save на сохранённом документе, доступность Undo/Redo и работа клавиатурных сокращений, сохранение сортировки, а также отображение на узком экране. Результат: тесты прошли, ошибок JavaScript не было; ошибка чтения в специально смоделированном сценарии ожидаемо выводилась в консоль. Реальная файловая система ОС не проверялась.
