# Проверки «Листа» v0.3.0

Проверки выполнены в headless Chromium с имитацией File System Access API. Взаимодействие с реальными системными диалогами и файловой системой ОС не проверялось.

Проверены сценарии: выбор рабочей папки, раскрытие вложенных директорий, открытие файлов; перенос длинных строк без горизонтальной прокрутки; размеры поля редактирования; сохранение изменений; создание файла и папки; переименование файла из заголовка и переименование папки; перемещение файла между папками; удаление папки; переключение светлой/тёмной темы; сворачивание сайдбара; адаптация под мобильную ширину и закрытие панели после открытия файла; замена рабочего каталога имитацией внешнего drag-and-drop.

До использования на важных данных необходимо вручную проверить запросы разрешений Chrome/Edge, сбои копирования и удаления, большие деревья директорий, перетаскивание каталогов из Finder/Проводника и повторное открытие после перезапуска браузера. Начните с тестовой копии папки.
\n## Дополнительная проверка исправлений v0.3.0\n\nВ Chromium с имитацией File System Access API проверены отсутствие внешней рамки при размере окна 1440×900 и 390×760, выбор темы через отдельное меню, отсутствие лишних кнопок, скрытие `.git`, `.DS_Store` и вложенного `.secret.md`, перенос файла в корень перетаскиванием на заголовок папки, перенос папки в корень на свободную область проводника, действие «Переместить в корень» через контекстное меню и его скрытие для объектов, уже лежащих в корне. Результат: проверки пройдены. Реальная файловая система ОС не использовалась.\n
