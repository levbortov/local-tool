# local-tool

Коллекция небольших автономных инструментов, работающих локально в браузере — без сервера и внешних зависимостей.

## Инструменты

### Лист — текстовый редактор

Простой текстовый редактор без форматирования. Исходник: [`tools/list/index.html`](tools/list/index.html).

Возможности: создать и открыть текстовый файл, редактировать содержимое, сохранить изменения в исходный файл, «Сохранить как», предупреждение о несохранённых изменениях, счётчики строк, слов и символов.

**Запуск:** скачайте `tools/list/index.html` и откройте в Chrome или Edge. Интернет и сервер не нужны. Для редактирования локальных файлов потребуется выбрать файл в системном диалоге браузера и разрешить запись. Некоторые функции могут зависеть от режима запуска браузера и настроек безопасности.

Сочетания клавиш: `Ctrl/⌘+S` — сохранить, `Ctrl/⌘+O` — открыть, `Ctrl/⌘+N` — новый документ.

> Это экспериментальный прототип. Перед редактированием важных файлов сделайте резервную копию.

## Принципы проекта

- Каждый инструмент по возможности работает как один самостоятельный HTML-файл.
- Данные остаются на компьютере пользователя.
- Нет обязательного бэкенда, сборки или внешних библиотек.
- Новые инструменты будут появляться в `tools/`.
