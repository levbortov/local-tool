# local-tool

Коллекция небольших автономных инструментов, работающих локально в браузере, без сервера, сборки и внешних библиотек.

## Лист — текстовый редактор (v0.3.0)

Исходник: [`tools/list/index.html`](tools/list/index.html). Скачайте этот файл и откройте в актуальном **Chrome или Edge**. Для операций с файлами браузер запросит разрешение.

### Возможности

- Проводник рабочей директории с раскрытием вложенных папок.
- Создание текстовых файлов и папок, переименование, перемещение и удаление файлов и папок внутри выбранной директории.
- Перемещение файлов и папок на другую папку в дереве перетаскиванием или через диалог выбора директории.
- Перетаскивание папки с компьютера в окно приложения для открытия нового рабочего пространства (в браузерах с соответствующей поддержкой).
- Открытие и редактирование текстовых файлов с сохранением в исходный файл.
- Редактирование имени открытого документа прямо в заголовке.
- Сворачиваемый проводник, который на узких экранах открывается поверх редактора.
- Системная, светлая и тёмная темы.
- Перенос длинных строк, стилизованная прокрутка и счётчики строк, слов и символов.

**Как использовать:** выберите рабочую папку, нажав на её название в левом верхнем углу. Выберите объект в проводнике, а затем используйте нижнюю панель инструментов или кнопку «⋯» возле имени. Редактирование названия документа сверху работает для файлов, открытых из рабочей директории.

**Сочетания клавиш:** `Ctrl/⌘+S` — сохранить, `Ctrl/⌘+Shift+S` — сохранить как, `Ctrl/⌘+O` — открыть файл, `Ctrl/⌘+N` — новый пустой документ, `Ctrl/⌘+Z` — отменить, `Ctrl/⌘+Shift+Z` — повторить.

### Ограничения и безопасность

- Прямой доступ требует **File System Access API** и разрешения пользователя; приложение ориентировано на Chrome/Edge. Перетаскивание директории с рабочего стола требует `DataTransferItem.getAsFileSystemHandle()`; если оно не поддерживается, используйте системный диалог выбора папки.
- Переименование и перемещение локальных файлов **не атомарны**: приложение сначала копирует, проверяет размер файлов, затем удаляет оригинал. При сбое могут остаться дубликаты; для больших папок операция может быть долгой. Проверки выполнялись на имитации файловой системы.
- **Удаление минует корзину и необратимо.** Перед ним запрашивается подтверждение. Перед экспериментами сделайте резервную копию важной директории.
- Редактор предназначен для обычного текста UTF-8; бинарные форматы не поддерживаются.
- Дерево обновляется по кнопке, изменения, внесённые другими программами, не отслеживаются непрерывно. Перед перезаписью открытого файла проверяется его размер и время изменения.
- После перезапуска браузера разрешение на доступ к папке может потребоваться снова. Сохранение темы в `localStorage` при запуске через `file://` зависит от браузера.

См. [результаты проверок](docs/QA.md).

## Принципы проекта

1. Один инструмент — по возможности один автономный HTML-файл.
2. Данные остаются на компьютере пользователя.
3. Нет обязательного сервера, аккаунта, сборки и внешних библиотек.
4. Каждый инструмент хранится в отдельной папке внутри `tools/`.
