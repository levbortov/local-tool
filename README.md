# local-tool

Коллекция небольших автономных инструментов, работающих локально в браузере, без сервера, сборки и внешних библиотек.

## Лист — текстовый редактор (v0.3.1)

Исходник: [`tools/list/index.html`](tools/list/index.html). Скачайте этот файл и откройте в актуальном **Chrome или Edge**. Для операций с файлами браузер запросит разрешение.


### Изменения v0.3.1

- Одна кнопка раскрывает все папки или сворачивает их — в зависимости от текущего состояния дерева. Шевроны показывают, какие папки открыты.
- Статусы файлов: на диске, не сохранено, изменён другой программой, ошибка чтения/сохранения. У родительской папки показан наиболее важный статус вложенных файлов даже в свёрнутом состоянии.
- В нижней панели рядом с кнопкой проверки — общий статус файлов рабочей директории.
- «Сохранить» неактивна, когда содержимое открытого файла совпадает с сохранённым; Undo и Redo активируются только при наличии соответствующих операций в истории изменений.
- Индикаторы отражают локальное состояние, **не облачную синхронизацию**: полная проверка делается при открытии каталога и нажатии кнопки обновления. Изменения текста без сохранения видны сразу.

### Возможности

- Проводник рабочей директории с раскрытием вложенных папок. Имена, начинающиеся с точки (например, `.git` и `.DS_Store`), скрыты.
- Создание текстовых файлов и папок, переименование, перемещение и удаление файлов и папок внутри выбранной директории.
- Перемещение файлов и папок на другую папку в дереве перетаскиванием или через диалог выбора директории.
- Перетаскивание папки с компьютера в окно приложения для открытия нового рабочего пространства (в браузерах с соответствующей поддержкой).
- Открытие и редактирование текстовых файлов с сохранением в исходный файл.
- Редактирование имени открытого документа прямо в заголовке.
- Сворачиваемый проводник с регулируемой шириной: перетащите разделитель или используйте стрелки клавиатуры при фокусе на нём. Ширина запоминается в браузере. На узких экранах проводник открывается поверх редактора.
- Системная, светлая и тёмная темы. Кнопка оформления расположена слева от кнопки скрытия проводника; в скрытом состоянии доступна в панели редактора.
- Перенос длинных строк, стилизованная прокрутка и счётчики строк, слов и символов.

**Как использовать:** выберите рабочую папку, нажав на её название в левом верхнем углу. Нажмите «⋯» рядом с файлом или папкой для действий с ними; правая кнопка мыши по пустому месту проводника позволяет создавать файлы и папки в корне. В нижней панели осталась только кнопка обновления списка. Редактирование названия документа сверху работает для файлов, открытых из рабочей директории.

**Сочетания клавиш:** `Ctrl/⌘+S` — сохранить, `Ctrl/⌘+Shift+S` — сохранить как, `Ctrl/⌘+O` — открыть файл, `Ctrl/⌘+N` — новый пустой документ, `Ctrl/⌘+Z` — отменить, `Ctrl/⌘+Shift+Z` — повторить.

### Ограничения и безопасность\n- При проверке используются метаданные файлов (размер и время изменения), а не побайтовое сравнение содержимого. Если сторонняя программа изменила файл, но сохранила и размер, и время модификации, изменение не будет обнаружено. Нет автоматического фонового слежения или синхронизации.\n- Рекурсивная проверка ограничена 1500 элементами и 20 уровнями вложенности; при превышении отображается статус частичной проверки.\n

- Прямой доступ требует **File System Access API** и разрешения пользователя; приложение ориентировано на Chrome/Edge. Перетаскивание директории с рабочего стола требует `DataTransferItem.getAsFileSystemHandle()`; если оно не поддерживается, используйте системный диалог выбора папки.
- Переименование и перемещение локальных файлов **не атомарны**: приложение сначала копирует, проверяет размер файлов, затем удаляет оригинал. При сбое могут остаться дубликаты; для больших папок операция может быть долгой. Проверки выполнялись на имитации файловой системы.
- **Удаление минует корзину и необратимо.** Перед ним запрашивается подтверждение. Перед экспериментами сделайте резервную копию важной директории.
- Редактор предназначен для обычного текста UTF-8; бинарные форматы не поддерживаются.
- Дерево обновляется по кнопке с круговой стрелкой, изменения, внесённые другими программами, не отслеживаются непрерывно.
- В нижней панели проводника можно раскрыть или свернуть все папки. Для больших деревьев действует предел обхода — 1000 папок и 20 уровней вложенности.
- Сортировка: папки сначала или общий порядок по имени, по возрастанию (А–Я) и убыванию (Я–А). Выбранный режим сохраняется в localStorage, если браузер это допускает. Перед перезаписью открытого файла проверяется его размер и время изменения.
- После перезапуска браузера разрешение на доступ к папке может потребоваться снова. Сохранение темы в `localStorage` при запуске через `file://` зависит от браузера.

См. [результаты проверок](docs/QA.md).

## Принципы проекта

1. Один инструмент — по возможности один автономный HTML-файл.
2. Данные остаются на компьютере пользователя.
3. Нет обязательного сервера, аккаунта, сборки и внешних библиотек.
4. Каждый инструмент хранится в отдельной папке внутри `tools/`.
