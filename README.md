# local-tool

Коллекция небольших автономных инструментов на HTML, CSS и JavaScript. Бэкенд, сборка и внешние библиотеки не требуются.

## Лист — текстовый редактор (v0.3.3)

**[Открыть редактор через GitHub Pages](https://levbortov.github.io/local-tool/tools/list/)** — основной способ запуска в актуальных Chrome или Edge.

GitHub Pages отдаёт только статический интерфейс по HTTPS. Работа с файлами происходит **в браузере на компьютере пользователя** через File System Access API; содержимое выбранных файлов не отправляется на GitHub или какой-либо бэкенд.

Скачать автономный исходник: [`tools/list/index.html`](tools/list/index.html). Его можно открыть напрямую через `file://`, но в некоторых конфигурациях Chrome такой запуск вызывает `SecurityError` при работе с файлами. При возникновении проблемы используйте ссылку HTTPS выше.

### Возможности

- Проводник с вложенными папками, сортировкой и массовым раскрытием/сворачиванием. Скрытые имена, начинающиеся с точки, не отображаются.
- Создание, переименование, перемещение (в том числе в корень) и удаление файлов/папок; контекстное меню и drag-and-drop.
- Изменяемая ширина сайдбара, мобильная выезжающая панель.
- Обычный текст UTF-8: редактирование, прямое сохранение, «Сохранить как», отмена и повтор изменений, индикатор несохранённого текста.
- Локальные статусы файлов и папок, проверка по кнопке обновления.
- Светлая, тёмная и системная тема. **В v0.3.3 тёмная тема переведена на нейтральную графитовую палитру**: цвет остаётся только для акцентов и статусов.
- Если браузер запрещает прямую запись, можно скачать отредактированный текст отдельным файлом.

### Как начать

Откройте редактор по HTTPS, нажмите на название рабочей директории и выберите папку. Сначала предоставляется доступ на чтение. Для изменения файлов при необходимости нажмите значок замка в заголовке проводника и подтвердите разрешение на запись. Файлы остаются на вашем компьютере.

Сочетания: `Ctrl/⌘+S` — сохранить; `Ctrl/⌘+Shift+S` — сохранить как; `Ctrl/⌘+O` — открыть; `Ctrl/⌘+N` — новый документ; `Ctrl/⌘+Z` — отмена; `Ctrl/⌘+Shift+Z` — повтор.

### Ограничения и безопасность

- Требуется File System Access API (ориентация на Chrome/Edge). Разрешения могут запрашиваться повторно после перезапуска браузера.
- Удаление происходит **без корзины**. Переименование/перемещение выполняются копированием с последующим удалением, а не атомарной операцией. Используйте резервные копии важных данных.
- Проверка внешних изменений выполняется по размеру и времени изменения файла при обновлении, а не постоянным наблюдением за содержимым. Большие деревья проверяются с ограничением по числу объектов и глубине.
- Фильтр скрытых файлов основан на точке в начале имени и не распознаёт системный атрибут «Скрытый» Windows.
- Для перетаскивания рабочей директории из ОС необходима поддержка соответствующего браузерного API.
- При запуске через `file://` часть функций записи может не работать; в тестируемом окружении пользователя проблему устранил переход на HTTPS.

## Принципы проекта

1. Один инструмент — по возможности один автономный HTML-файл.
2. Данные пользователя остаются локальными.
3. Нет обязательного бэкенда или сборки.
4. Каждый инструмент размещается отдельно в `tools/`.
