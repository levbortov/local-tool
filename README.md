# local-tool

Коллекция небольших автономных инструментов, работающих локально в браузере — без сервера и внешних зависимостей.

## Инструменты

### Лист — текстовый редактор (v0.2.0)

Простой редактор обычного текста. Исходник: [`tools/list/index.html`](tools/list/index.html).

Возможности:

- Открытие, редактирование и сохранение текстовых файлов прямо на диске (File System Access API).
- Проводник выбранной рабочей директории: вложенные папки, открытие и создание файлов, обновление списка.
- Три варианта оформления: системная, светлая и тёмная темы. Выбор сохраняется в браузере, когда доступен `localStorage`.
- Перенос длинных строк без горизонтальной прокрутки, адаптивное поле редактора и стилизованные полосы прокрутки.
- «Новый», «Открыть», «Сохранить», «Сохранить как», защита от потери несохранённого текста.
- Счётчики строк, слов и символов.

**Запуск:** скачайте `tools/list/index.html` и откройте его в актуальном Chrome или Edge. Интернет, локальный сервер, установка пакетов и сборка не требуются. Для работы с директориями нажмите «Папка…» и предоставьте браузеру доступ к выбранной папке. Для сохранения может потребоваться отдельное подтверждение разрешения.

**Сочетания клавиш:** `Ctrl/⌘+S` — сохранить, `Ctrl/⌘+Shift+S` — сохранить как, `Ctrl/⌘+O` — открыть, `Ctrl/⌘+N` — новый документ.

**Ограничения:** интерфейс предназначен для текстовых файлов в UTF-8, а не для бинарных данных. Дерево папок загружается при раскрытии; изменения, сделанные в другой программе, видны после обновления проводника. Доступ к папке зависит от разрешений браузера и не гарантирован между сеансами. При запуске через `file://` некоторые функции и сохранение настройки темы зависят от браузера.

> Экспериментальный прототип. Перед редактированием важных файлов сохраните резервную копию.

## Принципы проекта

- Каждый инструмент по возможности работает как один самостоятельный HTML-файл.
- Данные остаются на компьютере пользователя.
- Нет обязательного бэкенда, сборки или внешних библиотек.
- Новые инструменты появляются в `tools/`.
