# Клише — библиотека шаблонных ответов

Автономный инструмент для поиска и копирования готовых сообщений. Исходники на **Svelte 5 + TypeScript + Bits UI**. Итоговая сборка — **один HTML-файл**, открываемый через `file://` в Chrome/Edge. Приложение не использует сервер и не отправляет содержимое библиотеки в сеть.

## Запуск

Готовый файл после сборки — `dist/index.html` (в репозитории опубликован как `tools/cliche/index.html`): скачайте, откройте двойным кликом, выберите рабочую папку. Для первой проверки можно использовать приложенную папку `example-library`. Браузер прочитает файлы и вложенные папки с помощью `<input type="file" webkitdirectory>` (не File System Access API). Из корня выбирается первый по имени файл; если в корне нет сообщений, открывается первый файл из вложенных каталогов.

Для разработки: `npm install`, `npm run dev`. Для автономного файла: `npm run build`. Для проверок: `npm test`, `npm run check`. Для установки зависимостей нужен доступ к npm **только при сборке**. Готовый HTML не делает сетевых запросов.

## Возможности v0.1.1

- Боковая панель показывает только каталоги; файлы текущего каталога отображаются сверху как вкладки (Bits UI Tabs).
- Каждая карточка изначально свёрнута в одну строку. Нажатие на текст копирует **только тело сообщения**; шеврон разворачивает/сворачивает, звезда добавляет в избранное.
- Поиск по заголовку, тегам и тексту, частичные вхождения и русско-латинская транслитерация (`super` → `супер`, `star` → `стар`). По умолчанию вся библиотека; переключатель поиска по текущему каталогу (с вложенными) или тематике.
- Глобальный экран избранного. Избранное и тема/раскладка сохраняются в `localStorage` по событию, без таймера.
- Адаптивный сайдбар и сетка карточек для широких и узких окон; переключение сетка/список.
- Поддержка UTF-8 и файлов Windows-1251, если файл не декодируется как UTF-8.

## Формат

```text
[Заголовок #тег # тег2]
Содержимое первого сообщения

Содержимое второго сообщения

[Другой заголовок]
Содержимое третьего
```

**Пустая строка разделяет сообщения**. Заголовок и теги необязательны. Многоабзацные сообщения без другого разделителя неоднозначны — сохраняем формат, указанный для старого инструмента; его исходный парсер недоступен для сверки. Изменений в исходных файлах «Клише» не делает.

## Ограничения

- HTML, запущенный через `file://`, не имеет надёжного прямого доступа к файловой системе. Поэтому каталог выбирается для **чтения** обычным файловым диалогом; при изменении файлов извне выберите папку заново.
- Браузер не раскрывает абсолютный путь выбранной папки: избранное разделяется по **имени корневой папки**, и две папки с одинаковым именем могут разделять набор избранного. Карточки идентифицируются по пути файла и содержимому: после правки текста соответствующая звезда может пропасть.
- `localStorage` для `file://` зависит от браузера и расположения HTML. При запрете записи настройки действуют только до закрытия страницы. Приватный режим и очистка данных браузера могут их удалить.
- Копирование использует `execCommand('copy')` при `file://` и, если доступно, Clipboard API. Совместимость проверяйте в целевом рабочем браузере.
- Пустые папки браузерный выбор каталога не возвращает; приложения отображает каталоги с распознанными сообщениями. Скрытые dot-файлы исключаются; файлы больше 4 МБ и бинарные файлы пропускаются.
- Многочисленные карточки могут увеличивать потребление памяти: поиск работает по прочитанным текстам в браузере; виртуализация списка пока не реализована.

## Безопасность

Всё хранится локально: тексты находятся в памяти вкладки, избранное и настройки — в локальном хранилище браузера. Никаких сетевых запросов, analytics, внешних шрифтов или CDN в готовом HTML нет.

## Интерфейс v0.1.1

- Нет верхней шапки: управление избранным, темой и компоновкой находится в верхней строке сайдбара.
- Название рабочей папки — корень дерева. Справа от него две кнопки: повторно выбрать папку для обновления и выбрать другую. Через `file://` браузер не даёт перечитывать исходную директорию без повторного выбора. При повторном выборе папки с тем же именем сохраняются открытая тематика, поиск и развёрнутые карточки, которые всё ещё существуют.
- Сайдбар скрывается на любой ширине, его ширина изменяется мышью за разделитель (или стрелками при фокусе разделителя), настройка сохраняется в `localStorage`.
- Вместо дополнительных заголовков — вкладки с выделенной активной тематикой, компактный поиск, карточки и тонкая нижняя строка метаданных.
- Карточку можно нажать в любой свободной точке для копирования; звезда, шеврон и теги работают отдельно. Теги видны в свёрнутом состоянии, а нажатие на тег запускает глобальный поиск.
